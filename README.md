## 创作约束

- 招式因果链：每一招都写明「为什么出这一招」，前招被化解才出后招，不做动作关键词堆叠。
- 防守与闪避作为节奏切换的「气口」插入，而非独立段落。
- 参考图只取招式姿态、重心与对打关系，**明确禁止**把图上的文字、编号、色块分栏与表格带入画面；成片无字幕、无水印、无 UI、无 BGM，仅保留同期动作声。
